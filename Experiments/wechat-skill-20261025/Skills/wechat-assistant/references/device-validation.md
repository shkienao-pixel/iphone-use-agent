# 后续真机验收

当前状态：未连接设备、未安装 App、未调用真实模型、未发送消息、未点赞或评论。此文档是待执行方案。独立模块不会自行启动这些操作。

先确认实际 App 版本、系统语言/主题/字号、屏幕共享与 ESP32 输入能力。每项保存动作前后截图、当前对象、原子动作、时间和结果；不要收集无关私聊。对象和内容采用当次用户明确授权，不将本文的测试示例视为发送授权。

| 阶段 | 用例 | 通过依据 |
|---|---|---|
| 只读 | 搜索已有联系人；结果混有群与聊天记录 | 只进入联系人候选，资料读到正确账号；没有加好友/群操作 |
| 只读 | 同名或搜索结果更新延迟 | 不盲点，能列出实际候选；更新前不沿用旧行 |
| 只读 | 图形返回、Messages 复数、Moments 折行 | 从真实当前图识别，不为满足旧适配器补造 OCR |
| 只读 | 资料到个人朋友圈，再打开指定动态 | 账号、原始日期、正文/图片及导航连续；无年份不补年 |
| 只读 | 发现到朋友圈信息流 | 记录真实卡片、操作菜单入口和滚动容器；不触发赞评 |
| 草稿 | 单聊中文、换行、表情 | 准备、聚焦、长按、粘贴、核对分别记录；停在完整正确草稿 |
| 草稿 | 目标框已有另一段草稿 | 原草稿保留，不被自动覆盖 |
| 草稿 | 评论动态与回复某人 | 正确识别顶层评论；误入回复不提交 |
| 草稿 | 键盘弹出、浮钮遮挡、过期剪贴板 | 重新观察；无键盘不发键盘指令，遮挡不猜点 |
| 明确授权提交 | 单条文字消息 | 仅一个发送输入；新本人气泡全文一致，无等待/失败；不宣称已读 |
| 明确授权提交 | 指定动态首次点赞、再执行点赞要求 | 首次状态由未赞变已赞；第二次不点击取消 |
| 明确授权提交 | 指定动态顶层评论 | 唯一新增本人评论，内容和动态正确；其他人同文不算 |
| 恢复 | 点赞成功后暂停，评论未提交 | 恢复后只处理评论，已完成点赞不重做 |
| 恢复 | 提交后断连、旧像素系统重确认、进程重启 | 状态待核验，不重复发送、不凭旧像素报成功 |
| 长任务 | 滚动查找后压缩上下文 | 原请求、已核号对象、冻结动态、独立提交状态保留；无新增总步数上限 |

没有拿到真实菜单前，不运行任何假定“左边是点赞/右边是评论”的脚本。实机验收时先补齐 UI 地图，再逐项开放已观察分支。没有实测的语言/主题/内容类型继续写未验收。

机器规则测试、技能格式校验、模型离线场景测试、手机 UI 验收分别报告。一次成功不能推导长期稳定性或账号不受限制；出现实际异常提示就按当前任务保存并暂停。
