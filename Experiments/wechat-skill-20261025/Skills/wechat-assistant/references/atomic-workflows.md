# 原子流程

表里的“观察”只读当前新图，不带点击。每行是一个决策点；不是将整张表发送给执行器。不存在“一次执行整个发消息流程”的接口。

## 联系人搜索

| 前置状态 | 本次最多一个动作 | 下一次观察要确认 |
|---|---|---|
| 微信首页 | 点击当前搜索框 | 已进入搜索编辑态 |
| 查询不空且属于本次 | 点击清除，或一个已授权编辑键 | 查询确实清空；不要同时输入 |
| 搜索框可输入 | 输入一个可核对短段，或进入剪贴板输入支路 | 当前字段内容，不是旧结果 |
| 拼音组合态 | 点击当前候选词 | 已提交的字符是否正确 |
| 查询已完整 | 如实际需要，单独点击搜索/提交入口 | 新结果与查询一致 |
| 联系人候选唯一 | 点击 Contacts 中的当前行 | 进入资料还是聊天 |
| 进入聊天且未核号 | 点击对方实际头像 | 联系人资料与账号 |
| 当前资料完整 | 只核对并建立本次身份绑定 | 姓名/备注关系、账号原样、设备/共享流 |

## 准备文字：输入不会隐含提交

长中文文本优先使用宿主实际具备的剪贴板准备；它不等于发送。若必须返回宿主，每次通过一个实际可见导航动作完成，不能假设有后台剪贴板写入工具。

| 前置状态 | 原子动作 | 后置观察 |
|---|---|---|
| 宿主前台且内容工具可用 | 一次准备准确原文 | 真实准备回执、时效；无回执不继续 |
| 目标 App 在前台、输入框可见 | 点击输入框 | 焦点及已有草稿 |
| 空框、硬件键盘可用、ASCII 文本 | 一次输入一个字段的短段，无回车/Tab | 实际插入全文或部分字符 |
| 空框、已有有效剪贴板准备、无键盘 | 长按输入框 | 当前实际菜单 |
| 粘贴菜单已出现 | 点击粘贴 | 实际文本、输入法处理、换行/表情 |
| 输入已发生 | 只核对全文 | 一致才能进入发送准备 |
| 错字且当前文本确属本次 | 一个可观察的选区/删除动作 | 选区或删除结果，下一轮再修正 |
| 不属于本次的旧草稿 | 请求保留/处理选择 | 不清空、不覆盖 |

一次输入是一个字段的一段可检查文字，不是“一字符一模型请求”的强制规定。不能用带 Tab/回车的串跨字段或顺便提交。纯鼠标拼音逐键观察；粘贴路径可一次插入完整原文，再独立核对。

## 发送消息

1. 从已确认资料点击 Messages；观察实际单聊。
2. 按上表独立准备文字。
3. 只读核对：当前账号导航链、字段原文、当前发送入口。
4. 持久化提交意图；这一步没有手机输入。
5. 取得并消费一次性派发票据，宿主只执行一个点击。
6. 只读提交后新图：新增本人气泡、全文及等待/失败状态。
7. 独立记录已核验/失败/待核验；不把“计划发送”“鼠标已释放”记成发送成功。

4→5、5→6 任意中断都会保留 pending。进程恢复不重发票据。待核验只继续读取，不连续点击发送。

## 指定朋友圈

| 状态 | 一次动作或只读决策 |
|---|---|
| 已核号资料 | 点当前 Moments |
| 当前个人朋友圈 | 识别日期、正文和图片候选；需要向下时只做一次定位滚轮 |
| 候选需展开 | 点当前动态卡片；下一帧核对详情 |
| 目标唯一且内容明确 | 冻结本地目标绑定；无手机输入 |
| 操作入口可见 | 点菜单；观察实际选项 |
| 本人已赞 | 记原已满足；不点击取消 |
| 明确未赞且有点赞入口 | 保存独立点赞意图，然后派发一次点赞点击 |
| 点赞已派发 | 只读核验；必要时单独打开菜单读状态 |
| 点赞已核验，任务还需评论 | 点评论入口；下一帧核对顶层评论对象 |
| 评论编辑态 | 按文字准备表执行，每次一个动作 |
| 顶层对象及原文正确 | 保存独立评论意图，然后派发一次发送点击 |
| 评论已派发 | 只读核验该动态下的本次新增本人评论 |

信息流入口将前两行替换为：点 Discover，观察；点 Moments，观察；按指定作者与内容找候选。来自信息流的姓名也必须与已核号对象有可靠关系，不能仅以同名建立账号证据。

## 局部恢复

- 搜索只输入一半：先读当前词，只补差异。
- 粘贴动作超时：先读字段，不能再粘一次。
- 点赞 pending：只查状态，禁止再次 toggle。
- 点赞 verified、评论未提交：继续评论。
- 评论或消息 pending/uncertain：只核对新增项，禁止重新提交。
- 返回后页面仍处于菜单/编辑层：重新识别该层，不能按旧页面坐标操作。
- 重启丢失 live 绑定：重新核对资料与动态；归档是审计数据，不是恢复执行权限。
