## 双语与图形处理

- 中英文标签是候选词表，必须连同页面关系识别；Messages 复数、Weixin 名称、Moments 换行都需要实际适配。
- 返回与更多可能只有图形。真实像素检测结果可供宿主适配；模型自写 `localPixels` 标签不产生可信来源。
- 联系人“备注、Name、微信号”分开存。不能要求所有版本姓名重复两次，也不能把换行拼接算法应用到账号字符纠错。
- 深浅色、字体、动态字号、语言、键盘、AssistiveTouch/浮窗遮挡均未有覆盖证据。不得按这组图输出固定百分比坐标。

## UI 证据等级

1. 参考图：用于学习外观；永远不派发实时输入。
2. 合成 fixture：验证规则分支；只能进入 offline 核心。
3. 当前设备帧：宿主采集、当前设备/共享流、原始像素时间与系统确认时间；可支撑当前动作。
4. 提交后的新设备帧：像素变化晚于派发、对象和内容连续；才可能支撑业务结果。

目前具备 1、2。等级 3、4 的适配器与真机记录尚未实现。
