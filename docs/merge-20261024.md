# Sela 合并版 · Build 77

本次把「重新设计当前页面」和「设计手机 App 图标」中的已确认改动合入根目录的 `PhoneAgent.xcodeproj`，目标为 iPhone。

## 来源与落点

- `output/mac-app-preview/pending-ui-changes.patch`：正式 iOS 界面的工具、手机连接、App 连接、模型与记忆、全屏设置、办公授权恢复和 iPhone 原生服务。已排除 Catalyst、Mac 窗口、预览凭据和模拟器验收入口。品牌和系统图标进入正式资源目录。
- `output/native-panel/parity`：首页三条任务推荐、30 条任务目录、App 图标、记忆相关问候、日期判断、头像表情、语音暂停编辑与发送、附件菜单、回到最新消息、侧栏与消息样式。使用原生 SwiftUI 界面；本机偏好与日期规则通过 JavaScriptCore 复用已验证的纯计算代码，不引入网页演示的虚构回复或转写。
- `design/app-icon/sela/sela-app-icon-3d-1024.png`：接入正式 AppIcon，应用名称 Sela。
- `Tools/Connections`：保存办公 CLI 连接服务源码与原说明，没有复制本机账号、密钥、私有数据或已安装 CLI 目录。

任务推荐仅填入并聚焦草稿，发送由用户触发。问候只读取已启用本机记忆；不会自行读取日历或推断天气。头像使用保存的头部纹理、原矢量表情和原生动画，跟随实际任务状态。灵动岛完成标记采用绿色圆底和白色对勾；系统决定灵动岛展开时机。

照片与视频使用 iOS 系统选择器。视频支持本机预览，限制为 60 秒、10 MB；向模型发送带时间的三帧抽样图与范围说明，不发送原视频或声音。抽样结果不能代表完整视频。原有图片与文档附件功能保留。
