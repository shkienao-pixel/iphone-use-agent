## 已实现的外部 MCP 连接

Sela 对话 → 用户自己的 HTTPS `/mcp` 服务 → 用户在该服务上登录的小红书网页账号。

兼容参考项目：[xpzouying/xiaohongshu-mcp](https://github.com/xpzouying/xiaohongshu-mcp)。当前固定允许检查登录、获取登录二维码、搜索笔记、读取笔记详情。Sela 不根据服务端工具发现结果扩大权限；没有接入发布、点赞、收藏、发评论。

连接地址保存在本机设置中，访问密钥按服务地址分别保存在 Keychain。保存连接不等于账号已登录；扫码生成二维码也不等于登录成功，需要重新检查登录状态。断开本机连接不会删除远端账号登录信息。

搜索结果、正文、评论在 Sela 对话中展示，带原文链接、读取时间和实际加载范围。默认综合搜索，最多展示十条有效结果。读取评论请求最多二十条一级评论，尝试展开每条的前十条回复，卡片最多六十条去重评论和回复；不声称读到了全部评论。正文显示上限为一万二千字符，截断会注明。

后续读取只接受当前对话搜索得到且仍在内存中的笔记引用。服务访问密钥、笔记访问引用和分页标识不进入聊天归档。历史卡片、切换连接、重启后的旧结果需要重新搜索。取消或切换对话后，旧请求不能把结果写进新对话。

图片中的文字和视频口播不在该读取路径内。网页内容作为参考资料，不作为工具指令。

## 用户要求：手机按任务启动服务

用户希望在手机上启动相关任务时开启本地服务，结束后停止，手机自己执行，不依赖 Mac 或云服务器。

本地实现为：Sela 对话 → 应用内 MCP 主机 → 本机 WKWebView → 小红书网页。不监听局域网或公网端口，不需要服务器地址、域名、访问密钥或电脑辅助进程。新的未配置用户默认选择“这部手机”；原有外部 MCP 配置保留原模式。

MCP 主机实现初始化和只读工具调用，提供登录检查、搜索和详情读取；没有发布、点赞、收藏或发评论工具。每次读取启动本机网页，在结果返回、用户关闭或应用进入后台时停止并释放页面。处于登录界面或出错界面时保留网页供用户查看，关闭后同样释放。

网页登录使用 Sela 专用的持久化 WKWebsiteDataStore，登录信息保留在该网站存储中。不会读取或导入小红书 App、Safari 或电脑的登录 Cookie。用户可清除 Sela 内专用网页登录。每次读取前重新核验本机网页账号身份；账号与此前确认的身份不一致时，停止并撤销旧卡片的读取权限。

本机适配只读取网页提供的已加载状态，构造有边界的搜索、正文和评论数据；不调用逆向私有 API，也不把网页全文、账号资料或 Cookie 整体传入模型。评论读取最多进行三次滚动，不自动点击互动、发表或全部回复按钮。界面标明实际加载数量和范围。网站若没有返回所需结构，明确报未读取成功，不把缺少数据当成没有笔记或评论。

参考项目使用桌面 Go/Chrome，其发布包不能原样装进 iPhone。本机适配是新实现，网站可能要求登录、验证，或在当前网页版本上不提供所需页面；这些仍需真实账号验证。iOS 应用沙盒不会因 MCP 而开放其他 App 的登录状态或控制权限。

第一阶段以保持 Sela 前台为条件。进入后台时主动停止本机网页任务，避免声称已经具备后台常驻能力。没有为了本机服务新增音频、位置或后台权限。iOS 26 的 BGContinuedProcessingTask 也不能直接证明后台网页执行可用，后续若扩展必须独立验证。

当前没有购买服务器、部署云服务或开放公网端口，也未登录用户账号。内置的原生链路验证页面使用隔离的非持久化示例网页，明确标注示例，不代表真实网站数据。

## 验证范围

本地版本的冻结源码及完整结果位于 `output/xiaohongshu-local-20261025/`；外部连接先前结果位于 `output/xiaohongshu-mcp-20261025/`，以该目录下的验证报告为准。离线检查使用生产客户端、连接状态、解析器和对话宿主，注入传输层响应；不代表网站真实内容或账号操作验收。

手机本地 Build 132 已签名编译，源码清单与产物内记录一致。78 项功能离线检查通过（50 项生产 MCP/模式切换、16 项实际 JS 读取器、12 项对话宿主），另有 170 项路由、69 项跑腿和 130 项引用回归检查通过。

第二轮 3 项 iOS 原生界面测试通过：实际 WKWebView 加载本机示例 HTML，经过生产 JS、应用内 MCP 和对话解析返回正文/评论卡片；验证账号切换会撤销读取权限，以及停止后页面释放。第一轮发现的是验证页面重建丢失引用，已修复后重跑。示例数据始终标注为示例。

真实网站的匿名登录页也已在该模拟器的本机网页中打开，显示二维码和手机号输入入口；未输入手机号、验证码或执行账号登录。此结果只证明页面能显示，不证明真实账号搜索或评论读取已成功。

已使用上游 v2.5.5 的 macOS arm64 发布文件验证 SDK 握手与工具清单；对照发布资产摘要校验二进制。测试只监听随机本机回环端口，结束后退出进程。没有调用账号工具、登录、搜索或读取任何实际笔记。

签名编译、模拟器页面检查与真机验收分别记录；当前未安装到拔线的 iPhone，也没有验证真实账号数据。
