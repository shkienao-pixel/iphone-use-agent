## 原子动作与自动执行

十份技能共 61 个原子步骤，见 [动作索引](ios-native-atomic-actions.json)。每一步都给出输入、完成证据和失败/未知处理；编号是步骤，不是额外工具或执行授权。

明确请求在现有自动模式下收到即执行。202 已在真实物理发送路径验证自动启动；203 已验证同一正常 Agent 调用链自动执行。保留用户停止、系统授权和真正缺少的信息；不让模型把这些改成反复“执行任务”确认。

完成计数来自本任务真实回执。健康空结果不转成数值零，卧床不转成已睡时长；跨日、时区、范围和截断单列。未知写入不重发，不借其他任务的完成身份，不补填旧账本。

## 对话卡片

连接入口显示对应 App 图标、真实授权/连接状态和可打开的详情。完成后由实际回执生成对应 App 风格的结果卡片，分别标明创建时、查询时或历史结果；不能用规划、失败或未知提交生成成功卡片，也不添加没有执行能力的开关。

创建结果优先进入默认三项卡片，查询结果随后按时间排列，完整结果仍可展开。用户停留在旧消息时不强制滚到底；跟随最新消息时，卡片增高后继续保持结果和报告可达。

历史任务从最近 50 条中淘汰后，原对话保存只读结果快照。它只恢复已关联消息中的结果，不恢复工具权限、重试、继续或停止的执行权。M03 的 51 次实机调用已验证实际淘汰和原对话显示。

## 可复用的独立审计

`Tools/NativeAcceptance/audit_health_evidence.py` 只读取已保存证据，合并因任务日志上限而分散的原始条目，核对完整 SHA-256、UTF-8 长度、JSON 类型、日期范围、顺序和完成身份。相同范围的新读取可以有独立身份；是否违反不重复计划由声明范围另行核对。未对齐的多文件快照需要重新只读采集，不能补造结果或重复 SDK 调用。

```sh
python3 Tools/NativeAcceptance/audit_health_evidence.py \
  --case-directory /path/to/case --task ACTUAL_TASK_UUID \
  --manifest /path/to/manifest.json \
  --terminal-evidence /path/to/case/settled-evidence \
  --output /path/to/case/new-audit.json
```

输出不复述健康原值或查询日期，不覆盖已有结论。文件一致性、终态计数报告、设备来源、物理输入和卡片可见性分别记录；离线脚本不能单独证明设备来源。12 项独立异常夹具覆盖空值与零、布尔冒充数值、摘要/字节错误、不同任务、真实重复读取身份、日志淘汰、未决回执及停止后的部分结果，均未调用设备或模型。实际手机证据的额外回放也已核对，但本轮终态仍待完成。
