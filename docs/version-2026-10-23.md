# 2026-10-23 工作版本

## 包含的改动

- 模型调用本地 `phone_tool`，支持按当前文字元素点击、主屏搜索、搜索应用、设置页返回及键盘动作。
- 设备和页面范围内保存已经过页面转换验证的布局；布局过期、遮挡或共享来源改变时回退。
- 本地导航有界等待目标页出现，期间不重发输入；复用最后输入之后已经核对的真实结束画面，后续动作仍经过独立画面核验。
- 模型操作历史保留真实动作与工具回执，计时和指针唤醒不再挤占操作历史；分段计时便于定位等待。
- 静态屏幕通过轻移指针唤醒真实画面；相同动作仅在画面无实质变化时触发重复保护；停止共享保留已完成任务状态。
- 便携离线测试使用仓库内模拟数据，不依赖本机真实聊天记录。
- 提供实测 XIAO ESP32-S3 的配置覆盖文件，保留通用开发板默认配置。

## 验证

350 项离线检查通过；iOS 真机编译及开发签名安装成功。上传副本清除了个人签名 Team，并使用示例 Bundle ID，使用者需配置自己的签名。

iPhone App 通过已配置的模型 API 与 ESP32-S3 完成一次微信测试：进入文件传输助手，输入并发送一条 `hello`，观察到自己的消息气泡后完成。该次共 16 步、176.7 秒，5 次复用了本地工具核对的结束画面。宿主只负责安装、开启共享、连接配件、启动任务及观察；没有代为完成微信内点击、输入或发送。

此前也完成备忘录新建、粘贴及重新打开核对；长文由宿主预先查证并放到手机剪贴板，因此不能据此声称手机已独立完成资料检索和中文长文写作。

这些是单次任务结果，没有同任务新旧版本对照，不能宣称提速倍数或所有 App 均稳定。当前仍有会话身份核对绕路、硬件键盘隐藏时通用焦点无法由本地确认等限制；直接 HID 输入仅支持 ASCII，Unicode 长文仍需已验证的其他输入途径。
