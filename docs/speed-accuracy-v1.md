## 实际修改

- **计时与追溯**：生产 Engine / Harness / 模型请求分别记录准备、取屏、模型、OCR、输入、等待、上传、核验和本地流程；排他耗时可与总耗时对账，包含关系另外保留。失败准备、格式重试、取消、恢复和未知结果不会从样本中消失。上传没有事务时间戳就保持未知。
- **可用的记录入口**：设置 → 运行与基准记录，先核对起点，条件只用于下一次启动或恢复；可查看、导出本机运行 JSON。`scripts/run-benchmark.sh` 对全部样本复算中位数、范围、模型次数和结果分类，拒绝混合环境、未确认起点和不足三次的提速结论。
- **本地页面和短流程**：微信列表/搜索/聊天/朋友圈、小红书搜索/结果/笔记/评论有保守的多锚点识别；动态对象不记第几行。`wechat_send` 支持已有可识别页面上的内置文件传输助手短 ASCII 文本路径，最多四次输入，逐阶段检查对象、焦点、草稿全文与可见结果。它不是从任意主屏到完整微信业务的通用适配。
- **防重放与恢复**：业务身份与布局身份分开；会话别名、大小写、换操作 ID、换字体/尺寸、换配件不应让同一任务重复发送。输入/提交之前保存检查点；结果未知时硬停，禁止后续模型通过普通点击/输入或新任务绕过。设备页可记录用户核验结果，不自动补发。
- **等待和点击**：点击由对应 BLE 序号的释放回执结束，移除固定 160 毫秒等待和无条件的 80 毫秒轮询下限；旧空闲状态不能冒充新命令完成。新系统画面事件可提前唤醒下一轮观察，配置间隔是等待上限；这不等于已确认目标页面就绪。仍保留独立画面、目标及结果核验。
- **画面准确性**：除了全屏差异，检查小范围连通变化及动作目标周围的变化，避免小弹窗被全屏平均值稀释。OCR 控件 ID 绑定真实捕获流与像素采集帧；OCR 返回后和本地输入前复查 1.5 秒有效期、尺寸、共享与配件。
- **手机正文准备**：工作台可直接保存、恢复正文并在手机前台准备本机剪贴板；正文 ID 绑定 UTF-8 SHA256，中文、换行、表情和链接不做规范化改写。写入前保存状态，实际剪贴板全文回读一致后才获得短时准备回执；重启、停止或暂停不恢复执行授权。

指针差值移动**没有默认启用**。当前协议没有真实光标位置反馈，本轮又没有真机落点证据，不能用发送的位移量冒充实际位置。保留已有逐次归零、校准和运动参数；未刷新开发板、改变无线参数、读取或更换 API Key。

## 构建和版本绑定

```sh
bash scripts/check.sh
bash scripts/build-verified.sh simulator
bash scripts/build-verified.sh device
```

后两条分别编译模拟器和 iOS 真机平台的无签名 App，不安装到物理设备。构建脚本先计算已保存源码的 SHA256 清单，把 `Git 基线 + 源码摘要` 写进安装包，构建后再校验源码未变；清单在对应输出目录 `source-manifest.json`。普通 Xcode 构建未传入身份时会保留 unknown，不能用于可追溯基准。固件协议没有版本字段，仍记录 unknown，不把这份源码的固件版本当成实际板端版本。

本轮证据统一在 `output/speed-accuracy-20261023/`：任务书原件、原始源码基线、预定目标、检查/编译日志、源码清单、可审查差异和真机对照空表。合成时钟报告文件名含 `synthetic`，只证明计算工具可复算，不是真机速度样本。
