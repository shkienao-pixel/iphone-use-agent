# 页面与联系人适配：Build 74

本轮在已存在的 Build 73 工作区上补适配。没有更换长任务策略：默认长任务、无总步数上限、历史压缩、原始要求/子任务进度、暂停继续和停止保护保持原样。七份核心文件逐字对比本轮改前备份，结果另见输出目录的 `long-task-preservation.json`。

## 普通联系人

在“工作台 → 长任务工作区 → 聊天”保存准确标题、真实微信号和条数/日期范围。普通联系人先打开该人的资料页，再启动读取。生产驱动核对资料页微信号与独立页面结构，点击当帧唯一“发消息”，确认同共享流、同设备的真实聊天页面。昵称搜索、同名行、旧会话证明均不能替代身份核对。每次续读重新建立身份，已保存资料证明仅用于追溯。

空白会话里的返回、更多、添加图形来自当前真实截图的本地几何检测；图形本身不证明会话身份。文字与图形控件都绑定当帧，不重用旧坐标。消息与未读媒体继续按原证据流程归档和总结。通用系统弹窗保护仍较保守；例如独立出现的“OK/确定/允许”文字可能导致停止，未把所有聊天文字版式当已覆盖。

## 小红书

支持识别常见中文/英文的搜索、搜索结果、作者资料、笔记详情、评论、分享和筛选面板；这表示生产解析器和受控导航已接入，并非所有版本布局均已真机通过。

- 搜索结果的“综合”类别不等于已选排序。必要时打开当前筛选面板，读取真实已选排序/条件，完成后核对仍在同关键词。选择依据为明确已选文字，或实际截图中的红字加下划线/选中底色。
- 作者主页任务固定真实小红书号、笔记选中态和主页顺序，不按昵称切换作者。
- 详情没有来源 URL 时，驱动只点击实际观察的分享与复制链接。先记录真实剪贴板 changeCount，再校验复制变化；短链仅解析平台白名单域名，记录实际跳转链与最终笔记 ID。
- iOS 不允许后台读取剪贴板文字时，先保存并暂停。回本 App 点“核验已复制的笔记来源”，仅在保存的 changeCount、时间和来源链一致时补入；中间有其他复制或重启未知复制状态，不会自动再点复制。
- 原始 OCR、页面证明、截图摘要、捕获与系统确认时间逐批保存。截图摘要不是原 JPEG 归档；可导出明细和实际笔记链接，未读媒体不进入文字分析。统计仍只覆盖实际样本。

Build 73 存档向后兼容；旧版本只有可见标签的范围证明保留并标记 legacy，不追认为本轮已核验选中态。旧样本可读，续作只补新增笔记。

## 文件自动发送

先导入实际原件并选定顺序，填写准确微信号（内置文件传输助手可留空），明确授权保存这一批的自动发送范围。打开工作区、保持本 App 前台、共享整屏并连接配件后启动。固定计划 UUID 同时作为持久化操作 ID，换外层调用 ID 不能重新提交。

系统分享使用真实 `UIActivityViewController` 和原件 URL；只有 UIKit 的 `viewDidAppear` 发生、窗口确实存在后才建立呈现绑定。先保存可能提交的回执，再通过当帧控件进入微信、核对准确账号和完整原件确认页，实际 Send 前再保存选择证据，最多点击一次。

**自动路径要求扩展实际提供独立准确账号/内置身份、完整文件名及顺序、精确字节数、文件数量和明确原件模式。** 普通扩展只显示昵称、四舍五入大小或文件摘要时会停止。这是一条严格条件下可执行且有离线回放的路径；尚无证据证明当前安装的标准微信具备所有所需页面，不能称为通用微信自动发送已完成真机验收。

微信“+ → 文件 → 手机文件/Files”页面也有实际导航适配；浏览器元数据不能证明内容托管，不点击可能直接提交且原件无法独立核实的文件行。系统 completed 回调或远端文件气泡不能证明原文件 hash、收件成功、送达或已读。结果仅元数据时保留 unknown；未知阻断后续输入，但仍可只读查回执。取消、换配件、重启与新操作 ID 不能自动重发。

## 本轮验证与交付

执行 `bash scripts/check.sh`。离线检查覆盖生产页面解析器、驱动、原始字节/RGBA 证据、采集/读取/提交状态机、持久化与重启，外部 I/O 使用明确标记的回放。实际测试数量、日志、源码摘要和双平台无签名构建记录见 `output/adapters-20261023-v3/verification.json`。源包、可回放本轮差异与改前备份保存在同目录。

没有读取真实私聊、真实剪贴板或发送文件；没有调用真实模型，也没有实测短链网络。编译不等于安装、UI/权限、真实 OCR 准确性、BLE 执行或真机长任务验收。旧手机安装版需要重新签名安装后才有这些改动。
