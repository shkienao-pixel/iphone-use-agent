2026-10-25。Skill 位于 `Skills/xiaohongshu-assistant/SKILL.md`，本轮使用 Mac 上已安装并登录的小红书 9.49（9490866），没有安装虚拟 iPhone。

## Sela 如何加载

`PhoneAppSkillCatalog` 只从固定打包目录选择技能。视觉任务包含“小红书”、`xiaohongshu`、`rednote` 或已知分享短链时，`VisionClient` 把实际 Skill 正文加入手机操作指令，同时记录加载名称和字节数。无需 Codex 子 Agent，不改变现有模型连接。

这个加载入口独立于原生系统工具开关；仅系统工具模式不加载视觉操作指南。无关任务不加载，任务文本不能指定任意文件路径。缺失、错名、空正文和超预算资源会明确报错。

## 实操发现的短链问题

当前客户端真实复制的是 `https://xhslink.cn/o/…`。原代码没有接受该域名，且真实请求证明此入口 HEAD 返回 404、GET 返回 302。已在来源解析和跳转白名单加入准确的 HTTPS `xhslink.cn`，只对该域名使用 GET；没有开放其任意子域名、HTTP 或其他目的域名。

三条实际复制的链接已经通过生产解析器及来源校验，得到各自的标准笔记地址与 ID。保留精确域名、端口、用户信息、跳转次数、循环及最终来源校验；短链本身仍不作为笔记 ID。网络记录不保存最终链接的查询参数。

## 第三版：ESP32 鼠标与 iPhone 辅助触控

用户确认的手机输入路径是 `AgentEngine → MouseExecutor → BLETransport → ESP32 HID 鼠标 → iPhone 辅助触控 → 小红书`。以手机当前整屏画面定位；Mac 观察只提供入口识别经验。硬件键盘仍是独立的可选能力，不能因 ESP32 已连接就认为键盘可用。

实际代码中的滚轮动作此前只有 amount，停在打开评论的图标上就可能滚错容器。现在沿用既有 JSON 的可选 x、y：同时提供时，执行器用当前校准归位、移到目标区域，不点击，再发送滚轮；两者都省略时保留旧动作的当前指针行为。缺一个坐标、非有限数或越界会在输入前拒绝。定位后仍绑定原连接，取消或换连接不能继续发滚轮；Boot 模式不支持滚轮。等待对应序号的设备释放状态，而不是仅以 BLE 写入确认结束输入。设备回执仍不能证明页面真的滚动。

基础手机 Skill 与小红书 Skill 已同步：

- 评论面板先在当前图选择安全空白处，用 2–4 刻度小幅滚动，再核对实际滚动区域。不要点击评论来定位，也不把鼠标拖动当成必然有效的手指滑动。
- 纯鼠标中文输入通过当前屏幕键盘逐键选择，或在 Sela 前台准备原文后，在目标输入框长按、观察实际菜单、点“粘贴”。不使用 AX、setValue 或未声明的键盘能力；长文本没有可用输入路径时交给用户处理。
- 当前剪贴板准备有效期为 120 秒。“复制链接”会覆盖待粘贴文案，准备过期或发生复制后须重新准备；content_status 只有元数据，不能当作当前剪贴板回读。输入后还要核对真实目标与完整正文。
- 区分鼠标小圆点、辅助触控浮钮和 Sela 浮窗。目标被遮住先处理遮挡；键盘、评论层、菜单和返回改变布局后重新识别，不沿用原坐标。Home 仍需实际已确认的中键映射或可见辅助触控菜单。

这次定位滚动供视觉 AgentAction 使用。现有本地采集流程仍可发送 amount-only 动作，没有凭固定屏幕比例替它虚构可滚动区域，也没有宣称已迁移全部本地流程。

验证使用生产 MouseExecutor 与原始 BLETransport 方法，蓝牙 I/O 为模拟：66 项协议/动作检查、62 项输入执行/释放检查通过，覆盖纯鼠标能力、定位先于滚轮且没有点击/按住、旧动作兼容、错误坐标/校准/旋转/Boot 拒绝、定位中取消/重连阻止滚轮，以及旧闲置状态或 ATT ACK 不能冒充当前 HID 完成。两份 Skill 格式校验、最终模拟器编译、源码身份及实际构建包的精确技能正文加载也通过。原 577/242 项小红书采集/短链代码未修改，本轮不重复计入。

## 第四版：采集分页绑定与两小时阅读预算

本地采集现在也使用第三版的定位滚轮。采集器把本次范围内实际识别的列表项传给生产画面驱动；驱动校验元素 ID、完整边界、来源、画面及连接状态后，只发送一次带位置的滚动。已退出笔记后不沿用“返回”按钮处的鼠标位置。找不到目标则保存检查点并暂停，不推断全部读完，也不猜列表坐标。

新增完整分页回放覆盖“第一篇 → 当前返回入口 → 用新列表项定位滚动 → 第二篇”，并验证篡改坐标/来源/ID、新像素、换连接、校准失效和取消都会在滚动派发前拒绝。测试的画面、OCR 和输入边界是模拟；生产采集器与画面驱动代码参与运行。

运行计时改用单调时钟，累计检查点中的已用时，排除两次采集调用间已经结束的暂停间隔。当前调用内加载、网络等待和停止清理仍计时。每个打开笔记、返回、滚动、分享、复制和关闭动作之前都核验预算，耗尽后不派发下一个 GUI 动作；已经启动的鼠标动作正常收尾并释放，在途页面或网络可稍后返回，真实超时量保留。此检查不是逐个 HID 数据包的精确定时中断。来源交易中断继续保留原始证据和待核验状态，不自动补按复制或重放。
