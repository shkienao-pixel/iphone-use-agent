# Sela 快捷指令与未来测试目录

30 条任务，5 个 App。首页默认展示 3 条无框入口，同分时随机轮换，不重复上一组。`catalog.json` 为唯一任务内容源；`apps.json` 保存 App Store 图标来源和 SHA-256，`icons/` 保存原始图标。

预览中点击只填入输入框。所有真实执行用例初始为 `not_run`，待在 iPhone 上执行后逐条记录结果；页面排版、点击和随机换组测试不计为任务执行通过。

每个用例至少记录设备/系统/App 版本、输入条件、执行步骤、结果截图、实际结果与通过状态。

## 美团外卖

- [ ] **帮我点个外卖** (`meituan_takeout`)
  - 输入：配送地址、口味与忌口、预算
  - 验收：店铺和商品可配送；商品规格、数量与配送地址正确；实付总价包含包装费和配送费
- [ ] **来杯咖啡** (`meituan_coffee`)
  - 输入：配送地址、饮品与杯型、冷热与糖度
  - 验收：饮品规格与购物车一致；附加费用与到手价清楚
- [ ] **补点冰箱食材** (`meituan_groceries`)
  - 输入：配送地址、食材清单、数量或重量
  - 验收：品种与规格一致；缺货时记录替代选择并等待补充需求
- [ ] **这顿怎么更划算** (`meituan_compare`)
  - 输入：配送地址、菜品需求、预算
  - 验收：按相同份量比较；总价计入包装费、配送费和可用优惠
- [ ] **外卖送到哪了** (`meituan_track`)
  - 输入：目标订单
  - 验收：订单匹配；状态和预计送达时间来自当前订单页面
- [ ] **上次那份再点** (`meituan_reorder`)
  - 输入：历史订单、当前配送地址、商品规格
  - 验收：复核库存和当前价格；地址及规格正确且不误用过期信息

## 携程旅行

- [ ] **帮我订张机票** (`ctrip_flight`)
  - 输入：出发地与目的地、出发日期、人数与舱位
  - 验收：日期和机场正确；起降时间、舱位与含税总价一致
- [ ] **比比往返机票** (`ctrip_roundtrip`)
  - 输入：往返路线、去程与返程日期、出行人数
  - 验收：去返程日期正确；总价包含两个航段且人数正确
- [ ] **找个直飞航班** (`ctrip_direct`)
  - 输入：路线与日期、时间范围、预算
  - 验收：结果确为直飞；没有符合条件的航班时明确说明
- [ ] **挑家舒服的酒店** (`ctrip_hotel`)
  - 输入：城市、入住与退房日期、人数与预算
  - 验收：地点和房型床型匹配；入住晚数与总价正确
- [ ] **帮我找个高铁** (`ctrip_train`)
  - 输入：出发站与到达站、日期、人数与席别
  - 验收：车站和席别正确；区分有票、候补和售罄
- [ ] **看看旅行订单** (`ctrip_orders`)
  - 输入：目标订单
  - 验收：订单身份匹配；行程与预订状态准确

## 微信

- [ ] **朋友圈点个赞** (`wechat_like`)
  - 输入：目标动态的作者与内容
  - 验收：核对正确作者和动态；只点赞一次，已点赞时不反向取消
- [ ] **朋友圈留句评论** (`wechat_comment`)
  - 输入：目标动态、表达意图与语气
  - 验收：评论贴合目标动态；在正确动态下仅发表一次且内容一致
- [ ] **找找那段聊天** (`wechat_find-chat`)
  - 输入：联系人或群、关键词或时间范围
  - 验收：消息来源与范围正确；能定位回原对话中的消息
- [ ] **找个微信文件** (`wechat_find-file`)
  - 输入：联系人或群、文件名关键词或日期
  - 验收：来源和文件名称匹配；能打开目标文件
- [ ] **理理未读消息** (`wechat_unread`)
  - 输入：目标对话、消息范围
  - 验收：摘要有原消息依据；不混入其他对话内容
- [ ] **帮我拟一句回复** (`wechat_reply`)
  - 输入：目标消息、回复意图与语气
  - 验收：草稿符合上下文；草稿保留在正确对话且未自动发送

## 小红书

- [ ] **小红书找攻略** (`xiaohongshu_travel`)
  - 输入：目的地、行程天数、旅行偏好
  - 验收：内容与目的地匹配；每个参考结果都能打开原笔记
- [ ] **附近哪家好吃** (`xiaohongshu_food`)
  - 输入：地点、菜系与预算
  - 验收：地点匹配；区分笔记推荐和已核实门店信息
- [ ] **这件东西值不值** (`xiaohongshu_review`)
  - 输入：商品名称与型号、关注点
  - 验收：不混淆不同型号；优缺点对应到具体笔记
- [ ] **找点通勤穿搭** (`xiaohongshu_outfit`)
  - 输入：天气与场景、风格与预算
  - 验收：结果符合指定条件；参考笔记可打开
- [ ] **收藏实用笔记** (`xiaohongshu_save`)
  - 输入：目标笔记、收藏位置
  - 验收：收藏目标正确；已收藏时不取消或重复操作
- [ ] **帮我写篇笔记** (`xiaohongshu_draft`)
  - 输入：主题、素材、表达风格
  - 验收：标题与正文符合素材；保留草稿且未发布

## 时钟

- [ ] **帮我定个闹钟** (`clock_alarm`)
  - 输入：响铃时间、名称、重复规则
  - 验收：本地时间和重复日正确；闹钟已启用且避免重复创建
- [ ] **工作日叫我起床** (`clock_weekday`)
  - 输入：响铃时间、闹钟名称
  - 验收：仅周一至周五重复；时间正确且已启用
- [ ] **把闹钟改一下** (`clock_edit`)
  - 输入：目标闹钟、新时间或重复规则
  - 验收：编辑原闹钟而非额外新增；其他属性保留
- [ ] **暂时关个闹钟** (`clock_disable`)
  - 输入：目标闹钟
  - 验收：仅关闭目标闹钟；其他闹钟状态不变
- [ ] **看看现有闹钟** (`clock_list`)
  - 输入：查看范围
  - 验收：列出正确的时间与重复日；开关状态与实际界面一致
- [ ] **开一段专注时间** (`clock_timer`)
  - 输入：倒计时时长、计时器名称
  - 验收：实际时长正确；倒计时已启动且状态可核对


## 记忆联动验收

- [ ] 开启“使用本机记忆”后，已允许引用的相关偏好影响入口排序及点选后的草稿。
- [ ] 不相关的记忆不混入草稿；最多引用 3 条。
- [ ] 修改、删除、停用记忆或关闭总开关后，推荐及草稿同步更新。
- [ ] 无记忆时仍随机显示 3 条，点击只填草稿，不执行。
