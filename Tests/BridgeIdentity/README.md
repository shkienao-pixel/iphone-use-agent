# 连接配置与异步状态回归

`bash Tests/BridgeIdentity/run.sh` 提取当前完整的 `ExternalConnectionsCoordinator`，不改写生产方法、属性或初始化逻辑。为调用私有初始化方法，仅在同一份测试编译源文件末尾增加一个工厂扩展。

模型、用户默认值、凭据与 HTTP 请求均由本机替身提供。每次请求先冻结返回内容，再通过 continuation 门控交付；替身故意不自动响应取消，用来检查生产代码能否拒绝迟到结果。真实 `ConnectionCredentialStore`、系统 UserDefaults、HTTP 客户端和 DEBUG 设备配置导入不会编入测试进程。

覆盖更换端点、同一端点重新配对、A→B→A、旧健康/账号/断开/失败结果、请求前与返回后的取消、授权发起/轮询身份、批量刷新停止、重建协调器后身份恢复、旧格式兼容、非法配置及凭据保存失败，以及当前配置下的正常连接和失败行为。

该检查不证明实际钥匙串落盘、HTTP/TLS 行为、真实账号授权、手机 UI 或跨进程 UserDefaults 持久化通过验收。重建检查使用相同的内存存储和生产初始化方法，验证没有在初始化时生成新身份或虚构账号连接状态。

可使用 `PHONE_TEST_SOURCE_ROOT` 指向旧源码，运行相同回归以比较修复前后。失败时保留临时源文件、提取摘要、可执行文件和结果 JSON，并输出证据目录；成功时清理自己的临时目录。
