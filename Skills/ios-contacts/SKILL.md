# iOS 联系人

## 原子动作

编号是步骤标识，不是新增工具；按本次任务需要组合。

| 编号 | 单一职责 | 输入与完成依据 | 失败或未知时 |
| --- | --- | --- | --- |
| C01 | 明确查找对象 | 用户提供的姓名；仅查询需要的对象 | 真正有同名歧义才补充身份线索 |
| C02 | 确认授权范围 | 实际完整、有限或拒绝权限 | 拒绝不是查无此人，有限授权不是整个通讯录 |
| C03 | 查询一次 | `contact_search`，取得真实匹配数、返回项与截断状态 | 不发明反查或读取全部联系人能力 |
| C04 | 核对并消歧 | 各人的姓名、组织、电话、邮箱保持对应 | 不合并不同人的号码，不凭尾号认定同一人 |
| C05 | 呈现结果 | 使用真实结果卡片与报告，只展示需要的信息 | 返回联系方式不等于已拨号、已发消息或已联系 |

基本查询：C01→C02→C03→C04→C05。用户停止后不再发出下一次查询。

先确认宿主实际提供 `contact_search`。没有执行接口时说明缺少连接，不能把本 skill 或 Mac 通讯录操作当作 iPhone Agent 成功。

## 查询与核对

使用 `{"operation":"contact_search","query":"用户指定的姓名"}`。当前接口按姓名匹配，不承诺手机号或邮箱反查。只查询完成本次任务需要的对象；不自行枚举整个通讯录。

结果包含 `name`、`organization`、`phone`、`email`，以及 `matched_count`、`returned_count`、`truncated`。电话号码和邮箱每人最多各返回 3 项，不能称全部联系方式均已列出。按宿主真实返回值报告；号码展示格式可以不同，核对时保留国家码和分机，不凭尾号认定同一人。

零结果仅表示当前可见授权范围内没有匹配。有限授权不能证明其他联系人不存在。同名多项时分别保留各自字段；需要选定某人时询问必要的身份线索，不把不同人的号码合并。

## 权限与自动执行

自动模式收到明确查询任务后直接执行，不再询问是否开始或逐项确认；仅在用户主动开启审核时等待宿主审核。首次系统授权按 iOS 实际窗口处理。

权限被拒绝时报告权限错误，不把无权限说成查无此人，也不虚构回执。系统设置改变后，以真实权限状态和新查询核验恢复；用户中断的任务必须收到明确继续才恢复，保留原任务与失败记录。

收到明确继续指令后，按宿主恢复的原始任务范围重新核验当前授权和查询结果；历史错误不能代替当前状态，也不能带入其他任务的操作要求。

当前没有联系人创建、修改、删除、拨号或发送消息接口，不发明相关参数，不把号码返回当成已经联系对方。
