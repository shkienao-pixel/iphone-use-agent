# iOS 备忘录

## 原子动作

编号是工作步骤，不是新增工具。一次`notes_create`只创建一条，明确任务自动推进。

| 编号 | 单一职责 | 输入与完成依据 | 失败或未知时 |
| --- | --- | --- | --- |
| N01 | 固定标题与原文 | 保留完整Unicode、换行和文本边界，校验长度 | 不润色、补写或静默裁切 |
| N02 | 确定本机helper与目标 | 已配置快捷指令和默认或明确目标文件夹 | 缺少配置或目标不符就停止，不换文件夹 |
| N03 | 提交一条创建 | 宿主先保存待核对回执，再发出一次`notes_create` | 已交给系统的提交不能因取消而承诺撤回 |
| N04 | 等待系统交接与回传 | 关联同一次快捷指令回传，不重复提交 | 首次系统授权等待单列；停止后不恢复旧任务 |
| N05 | 核对回传原文 | 真实callbackID、completed和原文一致标记 | 缺回传、超时或原文不符保留未知，不自动重建 |
| N06 | 呈现并保存 | 宿主绑定同一次callbackID生成卡片，显示标题与配置目标 | 配置目标不能冒充系统文件夹或云同步已核对 |
| N07 | 长任务恢复与索引 | 仅使用本任务已识别的实际完成回传及输入摘要 | 无身份或无效项保留未知，不能按计划标题补齐 |

单条创建：N01→N02→N03→N04→N05→N06。批量任务逐条完成同一链，再用N07整理已完成索引；系统全文、文件夹和数量核对属于独立验收。

使用 `notes_create(title, content, folder_name?)`。这条路径由真实 Sela Agent 调用 iPhone 上的公开快捷指令入口，再执行系统备忘录创建动作。没有此宿主工具时不能声称本 skill 添加了能力；`content_create` 只保存 Sela 本机文件，不能当作 Apple Notes 成功。

自动模式收到明确创建任务后直接执行，不再要求点击“执行任务”或逐项批准。只对真正缺少的内容澄清。保留完整标题、正文、Unicode、表情和换行，不擅自润色、补写、裁切或归一化。标题为单行、最多 160 字，正文为 1–6000 字且不超过 24000 UTF-8 字节；超限应说明，不能静默截断。

用户指定文件夹时传其准确名称，必须匹配宿主已配置的目标。没有指定时省略 `folder_name`，直接使用已配置的默认文件夹，不要求用户重复提供。未配置或指定目标不符时如实报告，不改用其他文件夹，不发明快捷指令名或 Notes 标识。

首次准备时，在本机快捷指令里设置“创建备忘录”，内容使用“快捷指令输入”，绑定目标文件夹，并关闭运行后打开备忘录；在 Sela 的备忘录连接页保存名称和目标。首次系统授权按实际要求处理，后续复用已有配置和授权。此设置属于准备工作，不能算 Agent 创建成功。

只依据真实回执报告：`shortcut_completed` 表示快捷指令回传完成，`output_matches_requested_text` 表示回传的标题加正文与提交文本逐字节相同。`expected_folder` 是配置目标，`folder_independently_verified=false` 时不得说实际文件夹或重复数量已经核对。独立验收还需打开系统备忘录，检查正确文件夹、完整正文和同标题数量；不将操作员或 XCTest 核对算成 Agent 读取能力。

宿主如提供 `current_task_only_shortcuts_callbacks` 账本，可用 `completed_shortcuts` 核对本任务实际提交的标题、配置目标、输入摘要及成功回传，生成原任务要求的索引。日志压缩后继续依据这些持久回执，不要求用户补交已有证据或再次批准执行。旧回传缺少标题身份、元数据无效或写入仍待核对时，保留未知，不按计划标题补齐或重建。此账本不读取系统备忘录，也不证明当前仍存在、实际文件夹、同标题数量或云同步。

宿主在跳转前保存待核对写入回执。同一任务的未知提交不能靠重试、修改标题或另选目标绕过。取消、超时、缺少回调或正文不符时保留未知状态，不宣称没创建，也不自动再建一条。停止 Sela 会结束等待和后续派发；已经交给系统的外部操作仍可能提交，不能承诺撤回它。迟到回调不能恢复已停止的任务。

尚未提交的下一步在后台等待返回 Sela 前台时，不重新发送或创建，也不把等待当成功。已交给快捷指令的操作继续按原回传身份核对。用户停止或进程重启后，不因返回前台而恢复旧任务；保留原始状态和未知结果。

当前没有 Notes 搜索、读取、追加、编辑、删除或云同步验证工具；不要编造这些操作或据此读取无关私人备忘录。完成报告放在 `finish.text`，保留已验证事实和剩余限制，不只说“已处理”。

成功后保留宿主从同一次真实快捷指令完成回传生成的对话备忘录卡片，展示原文标题和配置目标，随任务历史保存。卡片中的配置目标不能升级为实际文件夹或云同步已核对；未知提交不能生成成功卡片，也不能因为卡片未出现而重建。

实际验收范围见 [references/acceptance.json](references/acceptance.json)。公开回传参数依据 [Apple 快捷指令文档](https://support.apple.com/en-ca/guide/shortcuts/apdcd7f20a6f/ios)。
